# TK-16.04 — Resultados anônimos para RH

Status: 🟡 — implementação concluída; roteiro manual de acessibilidade pendente
Épico: EP-16 · Spec: `docs/specs/EP-16-pesquisa-de-satisfacao.md`  
Depende de: TK-12.07, backend TK-16.02  
Tamanho: M  
Requisitos: RF-34, RN-18, RN-04

## Contexto

Incluir nos relatórios do RH uma seção com as métricas da pesquisa e comentários sem metadados. Não exibir respostas individuais nem filtros que reduzam a população.

## Critérios de aceite

- **Dado** RH/ADMIN, **Quando** abre os relatórios, **Então** consulta contagem, distribuições, média de recomendação e comentários anônimos.
- **Dado** zero respostas, **Quando** abre a seção, **Então** vê estado vazio, contagens 0 e média indisponível.
- **Dado** resposta carregando ou erro, **Quando** a tela mostra o estado, **Então** preserva foco, anuncia erro e oferece retry sem ocultar outras áreas do relatório.
- **Dado** comentários com HTML, **Quando** são exibidos, **Então** aparecem como texto escapado.
- **Dado** colaborador ou massoterapeuta, **Quando** tenta consultar, **Então** a autorização do backend impede acesso.

## Acessibilidade

- Rótulos de pergunta e alternativa associados semanticamente; distribuições com tabela equivalente e resumo textual.
- Comentários como lista sem região de rolagem exclusiva; ordem de leitura segue a ordem do conteúdo.
- Contraste, teclado, foco visível, zoom 400%, `forced-colors` e leitor de tela conforme `docs/acessibilidade.md`.

## Testes esperados

- Relatório com dados/sem dados, renderização de cada distribuição, comentários escapados, erro e retry.
- Axe, teclado, zoom/reflow e cores forçadas.

## Validação da implementação

- `npm run typecheck`, `npm run lint`, `npm test` (287 testes) e `npm run build`: aprovados.
- `npm run check:contrast`: 40 pares em 7 temas aprovados.
- `npm run test:a11y`: 294 cenários aprovados, incluindo a página de relatórios com axe, teclado/foco, zoom de 400%, cores forçadas e movimento reduzido.
- O roteiro manual com NVDA + Chrome e conferência visual manual não pôde ser executado neste ambiente sem navegador interativo/leitor de tela; permanece pendente.
