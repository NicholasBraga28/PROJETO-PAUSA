Depende de: —
Tamanho: M
Requisitos: RN-04

## Contexto

O código veio em JavaScript. A migração para TypeScript strict é a base de todo o EP-09: os contratos da API (TK-09.03), as rotas por papel (TK-09.04) e os componentes compartilhados (TK-09.05) dependem de tipos. A migração **não muda comportamento** e mantém os arquivos no lugar; a mudança de pastas é o TK-09.02.

## Critérios de aceite

- **Dado** o projeto migrado, **quando** rodo `npm run typecheck`, **então** não há erros, com `strict`, `noUncheckedIndexedAccess`, `noImplicitOverride` e `verbatimModuleSyntax` ligados.
- **Dado** o código-fonte, **quando** procuro `any` explícito, `as unknown as` ou `!` de non-null, **então** não encontro nenhum.
- **Dado** os testes atuais, **quando** rodo `npm test`, **então** todos passam, agora em `.test.tsx`, sem perder nenhum caso.
- **Dado** a aplicação no navegador, **quando** faço reserva, cancelamento e check-in, **então** o comportamento e os anúncios são os mesmos de antes.
- **Acessibilidade:** os testes de axe e por papel e nome continuam passando; nenhuma prop de acessibilidade (`aria-*`, `role`, `aria-label`) é removida para satisfazer o compilador.
