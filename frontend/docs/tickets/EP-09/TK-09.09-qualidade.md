## Contexto

O frontend não tem Prettier nem `typecheck` e tem comentários espalhados (o backend proíbe). Este ticket alinha as ferramentas às do backend e limpa o código antes da mudança de pastas.

## Critérios de aceite

- **Dado** o projeto, **quando** rodo `npm run format:check`, `npm run lint` e `npm run typecheck`, **então** passam.
- **Dado** o lint, **quando** roda, **então** inclui `jsx-a11y` strict, `react-hooks`, `typescript-eslint` (com `no-explicit-any` e `no-non-null-assertion`) e `react/no-danger`.
- **Dado** o código-fonte, **quando** procuro comentários, **então** só restam os do `.env.example`; o que eles explicavam virou nome, teste ou texto no `CONTEXT.md`.
- **Dado** o código-fonte, **quando** procuro código sem uso, **então** ele foi removido. A cena do hero (`LogoWire`) fica e o `Diamond.jsx` sai (D-24).
- **Acessibilidade:** a remoção de comentários não remove nenhuma prop de acessibilidade; o porquê das decisões de acessibilidade (por exemplo, "a barra do dia é só visual") vai para o `CONTEXT.md` ou para o nome do teste.
