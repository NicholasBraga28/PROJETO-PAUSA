## O que entregar

- `POST /therapists/me/appointments/:id/no-show`, só `THERAPIST`:
  - só `POSSIBLE_NO_SHOW` → `NO_SHOW`, ator `THERAPIST`, pela tabela de transições e `updateMany` condicionado;
  - em `CONFIRMED` (dentro da tolerância), `409` "Ainda está dentro da tolerância de atraso." (RN-02);
  - atendimento de outro massoterapeuta, `404` igual ao de inexistente;
  - resposta "Ausência registrada." mais o próximo, se houver.
- `AuditEvent` `APPOINTMENT_MARKED_NO_SHOW` com o massoterapeuta como ator; nome falado no catálogo de auditoria do RH. Nenhuma coluna nova em `Appointment`.
- Cancela os avisos pendentes daquele atendimento, como o cancelamento já faz.
- Novo evento na `AppointmentEvents`: `emitNoShow` / `onNoShow`, com `{ appointmentId, therapistId, markedById }`.
- Linha nova na matriz de permissões.

## Critérios de aceite

- [x] **Dado** um atendimento em `POSSIBLE_NO_SHOW` e um próximo, **quando** o massoterapeuta marca ausência, **então** vai para `NO_SHOW` e responde "Ausência registrada. Próximo: Bruno, às 15h.".
- [x] **Dado** um atendimento ainda `CONFIRMED`, **quando** marca ausência, **então** recebe `409` com a frase da tolerância e nada muda.
- [x] **Dado** um atendimento em qualquer outro estado, **quando** marca ausência, **então** recebe `409` com frase e nada muda.
- [x] **Dado** um atendimento de outro massoterapeuta, **quando** marca ausência, **então** recebe `404` igual ao de inexistente.
- [x] **Dado** a marcação, **quando** se consulta a auditoria, **então** há `APPOINTMENT_MARKED_NO_SHOW` com o massoterapeuta como ator, e o nome falado aparece na auditoria do RH.
- [x] **Dado** avisos pendentes do atendimento, **quando** marca ausência, **então** eles são cancelados.
- [x] **Dado** um listener registrado, **quando** marca ausência, **então** recebe o evento com `appointmentId`, `therapistId` e `markedById`.
- [x] **Dado** o atendimento marcado, **quando** abre a agenda, **então** ele aparece como "ausente" e não conta em `remainingCount`.
- [x] **Dado** `HR`, `ADMIN` ou `EMPLOYEE`, **quando** chama a rota, **então** recebe `403`.
- [x] `npm run test`, `npm run test:e2e`, `npm run lint` e `npm run build` passam.
