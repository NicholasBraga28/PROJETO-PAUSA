- O legado tem abertura, ajuda e parar, mas sem "repetir" e com textos no controller.
- Não depende de saber quem fala: funciona inclusive em aparelho não vinculado.

## O que entregar

- `LaunchRequest`: saudação curta com dois exemplos do que dizer; sessão aberta.
- `AMAZON.HelpIntent`: no máximo três comandos e reprompt.
- `AMAZON.RepeatIntent`: repete a última fala guardada nos `sessionAttributes` pelo `AlexaResponseBuilder` (toda resposta guarda a sua). Sem fala anterior, responde como a ajuda.
- `AMAZON.StopIntent` e `AMAZON.CancelIntent`: "Até logo." e encerra; descartam uma ação pendente de confirmação sem alterar nada.
- `AMAZON.FallbackIntent` e qualquer pedido sem handler: sugestão curta do que dizer.
- `SessionEndedRequest`: resposta vazia, sem fala.
- Erro inesperado: "Não consegui consultar a agenda agora. Tente de novo em instantes."; log com tipo de requisição, nome do intent e IDs, nunca a fala nem o código de pareamento.
- Textos pelo catálogo de mensagens.

## Critérios de aceite

- [x] **Dado** um `LaunchRequest`, **quando** chega, **então** a resposta tem a saudação com dois exemplos e a sessão fica aberta.
- [x] **Dado** "ajuda", **quando** chega, **então** ouve no máximo três comandos, com reprompt.
- [x] **Dado** uma consulta respondida, **quando** a próxima fala é "repetir", **então** ouve exatamente a mesma frase.
- [x] **Dado** nenhuma fala anterior, **quando** diz "repetir", **então** ouve a ajuda.
- [x] **Dado** uma ação pendente de confirmação, **quando** diz "parar" ou "cancelar", **então** ouve "Até logo.", a sessão encerra e nada muda.
- [x] **Dado** uma frase não entendida, **quando** chega o `FallbackIntent`, **então** ouve uma sugestão do que dizer.
- [x] **Dado** um `SessionEndedRequest`, **quando** chega, **então** a resposta não tem fala.
- [x] **Dado** um erro inesperado, **quando** acontece, **então** ouve a frase genérica e o log não tem fala nem nome.
- [ ] **Dado** o Echo de teste, **quando** usa ajuda, repetir e parar, **então** funcionam como acima.
- [x] `npm run test`, `npm run test:e2e`, `npm run lint` e `npm run build` passam.
