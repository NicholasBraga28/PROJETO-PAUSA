## O que entregar

- Interface `AlexaIntentHandler` com `canHandle(request)` e `handle(request): Promise<AlexaReply>`. Cada intent é uma classe registrada no multi-provider `ALEXA_INTENT_HANDLERS`.
- `AlexaDispatcher`: percorre os handlers em ordem e usa o primeiro que aceitar (Chain of Responsibility). Um handler de fallback no fim garante resposta.
- `AlexaReply`, tipo do domínio da skill: fala, reprompt opcional, se encerra a sessão, diretiva de confirmação opcional e atributos de sessão. Só o `AlexaResponseBuilder` conhece o JSON da Amazon. A fala é SSML com escape, como hoje.
- `AlexaRequestContext` resolvido pelo dispatcher antes do handler. Neste ticket, o massoterapeuta vem do `ALEXA_USER_MAP`; o TK-07.05 troca a fonte sem mexer nos handlers.
- O controller só despacha. O `ask-sdk-core` sai do caminho da requisição; os tipos vêm do `ask-sdk-model`.
- Intents atuais migrados para classes, com os nomes novos em inglês do modelo (`NextAppointmentIntent`, `TodayAgendaIntent`, `WhoArrivedIntent`, `StartSessionIntent`, `FinishSessionIntent`, `CancelAppointmentIntent`), chamando os services do EP-06 (`TherapistAgendaService`, `TherapistActionsService`). As frases definitivas vêm no TK-07.06 e no TK-07.07; aqui o comportamento atual se mantém.
- Todo "agora" e "hoje" vem do `Clock`, com o dia em `America/Sao_Paulo`. Nenhum `new Date()` no módulo.
- Textos falados que hoje estão no controller vão para o catálogo de mensagens.
- Erro inesperado num handler: `200` com a frase genérica de falha do catálogo.

## Critérios de aceite

- [x] **Dado** um `IntentRequest` de um intent migrado, **quando** chega ao endpoint, **então** a resposta tem o mesmo conteúdo falado de antes da migração.
- [x] **Dado** um intent sem handler, **quando** chega, **então** o fallback responde com uma sugestão do que dizer.
- [x] **Dado** um handler que lança erro inesperado, **quando** a requisição chega, **então** a resposta é `200` com a frase genérica de falha, e o log só tem tipo de requisição, nome do intent e IDs.
- [x] **Dado** o `FakeClock` às 23h30 em `America/Sao_Paulo` (02h30 UTC do dia seguinte), **quando** alguém pede a agenda de hoje, **então** a resposta é sobre o dia de São Paulo.
- [x] Um intent novo entra criando uma classe nova e registrando-a, sem editar o controller nem os outros handlers.
- [x] O módulo `alexa/` não tem `new Date()`, `SkillBuilders` nem strings faladas fora do catálogo.
- [ ] **Dado** o Echo de teste com o modelo do TK-07.04 publicado, **quando** alguém faz as três consultas, **então** elas respondem com dados reais (Fase 5 do `docs/alexa/roadmap.md`).
- [x] `npm run test`, `npm run test:e2e`, `npm run lint` e `npm run build` passam.
