## O que entregar

- **Migração:** `AlexaDevice` perde o `therapistId` e mantém o `deviceId` único. Nova tabela `alexa_device_therapists` (`AlexaDeviceTherapist`) com `alexaDeviceId`, `therapistId` e `pairedAt`, com restrição única no par. A migração copia os vínculos existentes.
- **`PairDeviceIntent`** ("vincular código {code}"):
  - completa o número com zeros à esquerda até 6 dígitos (L8) e recusa o que não tiver 6 dígitos;
  - consome o código numa transação: precisa existir, não estar consumido, não estar expirado (pelo `Clock`) e ser de massoterapeuta ativo; grava `consumedAt` e `consumedByDeviceId`;
  - cria o `AlexaDevice` se não existir e **acrescenta** o massoterapeuta aos vinculados (se já estava, nada muda);
  - duas Alexas com o mesmo código ao mesmo tempo: só uma vincula;
  - `AuditEvent` `ALEXA_DEVICE_PAIRED`, com o dono do código como ator e os IDs do aparelho e do código (nunca o código em si);
  - sucesso: "Pronto. Esta Alexa agora atende {primeiro_nome}."; inválido, usado ou expirado: "Código inválido ou expirado. Peça um novo código ao RH." (uma frase para os três casos);
  - quem acabou de vincular fica identificado no resto da conversa.
- **`AlexaSpeakerResolver`**, que substitui o `ALEXA_USER_MAP` no `AlexaRequestContext`. Recebe o `deviceId`, o massoterapeuta já identificado nos `sessionAttributes` e o instante do `Clock`. Devolve **identificado**, **precisa perguntar** (com candidatos) ou **não atende**. Só considera vinculados com usuário ativo, nesta ordem:
  1. já identificado nesta conversa e ainda vinculado e ativo;
  2. slot `name` da própria frase que corresponde a um único vinculado;
  3. um único vinculado;
  4. exatamente um vinculado com `ScheduleSlot` contendo o instante atual;
  5. senão, perguntar.
- **Pergunta "Quem está falando?"**, com os primeiros nomes dos vinculados como entidades dinâmicas do slot `name` (`Dialog.UpdateDynamicEntities`). O pedido original (intent e slots) fica nos `sessionAttributes` e é executado quando o nome chega (`IdentifySpeakerIntent`), sem o massoterapeuta repetir.
  - Nome que não é de nenhum vinculado: "Esta Alexa atende {nomes}. Quem está falando?", no máximo duas tentativas, depois encerra sem agir.
  - Dois vinculados com o mesmo primeiro nome: as entidades usam nome e sobrenome deles, e a pergunta pede o sobrenome.
- **Aparelho sem vínculo:** "Este aparelho ainda não está vinculado. Peça ao RH um código de vinculação." e encerra. Sem vínculo, só funcionam o pareamento, a ajuda, o parar e a abertura.
- `personId` não é usado (L3). Logs só com IDs: nada de nome, frase falada ou código.

## Critérios de aceite

- [x] **Dado** um código válido de um massoterapeuta ativo, **quando** alguém diz "vincular código" num aparelho novo, **então** o aparelho é criado, o massoterapeuta é vinculado, o código é consumido, a auditoria é gravada e a resposta é "Pronto. Esta Alexa agora atende {primeiro_nome}.".
- [x] **Dado** o código `048213`, **quando** chega o slot `48213`, **então** o vínculo funciona.
- [x] **Dado** um código inexistente, usado ou expirado (pelo `FakeClock`), **quando** alguém tenta vincular, **então** ouve a mesma frase de recusa e nada muda.
- [x] **Dado** um aparelho com Bruno vinculado, **quando** Diana vincula o código dela, **então** os dois ficam vinculados.
- [x] **Dado** duas requisições simultâneas com o mesmo código, **quando** processadas, **então** só uma vincula.
- [x] **Dado** um único vinculado, **quando** ele pergunta pelo próximo, **então** a Alexa responde sem perguntar quem fala (US 10a).
- [x] **Dado** Bruno e Diana vinculados e só Diana com `ScheduleSlot` agora, **quando** alguém pergunta pelo próximo, **então** a resposta é sobre a agenda de Diana.
- [x] **Dado** os dois com `ScheduleSlot` agora, **quando** alguém pergunta pelo próximo, **então** ouve "Quem está falando?"; **quando** responde "Diana", **então** ouve o próximo de Diana sem repetir o pedido, e o resto da conversa não pergunta de novo.
- [x] **Dado** "aqui é a Diana, quem é o próximo", **quando** chega com o slot `name`, **então** a Alexa responde sem perguntar (US 10f).
- [x] **Dado** um nome que não é de nenhum vinculado, **quando** dito duas vezes, **então** a Alexa diz quem pode usar e depois encerra sem agir.
- [x] **Dado** dois vinculados com o mesmo primeiro nome, **quando** a Alexa pergunta, **então** pede o sobrenome.
- [x] **Dado** um vinculado desativado, **quando** fala com a Alexa, **então** não é atendido.
- [x] **Dado** um aparelho sem vínculo, **quando** alguém faz uma consulta, **então** ouve a frase de aparelho não vinculado e a sessão encerra.
- [x] O `ALEXA_USER_MAP` não existe mais no código nem no `.env.example`.
- [x] **Dado** o Echo de teste, **quando** o massoterapeuta do seed vincula com um código gerado pelo RH, **então** as consultas respondem com a agenda dele (Fase 6 do `docs/alexa/roadmap.md`).
