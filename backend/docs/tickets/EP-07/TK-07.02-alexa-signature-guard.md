## Contexto

- Hoje qualquer pessoa consegue chamar `POST /api/alexa` e se passar pela Amazon. Sem a verificação, a skill também seria reprovada na certificação.
- Depende do TK-07.01 porque o teste no aparelho confirma que requisições reais da Amazon continuam passando.

## O que entregar

- `AlexaSignatureGuard` na rota `POST /api/alexa`, que continua `@Public()` (a Amazon não manda `x-user-id`).
- Interface `AlexaRequestVerifier`, token `ALEXA_REQUEST_VERIFIER`. A implementação real é um Adapter sobre os verificadores do `ask-sdk-express-adapter`: assinatura (`Signature-256`/`Signature` + `SignatureCertChainUrl`), cadeia do certificado e domínio `echo-api.amazon.com`.
- O guard confere também:
  - o `timestamp` da requisição contra o `Clock`, com tolerância de 150 s (constante técnica nomeada);
  - o `applicationId` contra `ALEXA_SKILL_ID`, que passa a ser obrigatório na validação de ambiente fora de `test`.
- A assinatura é verificada sobre o corpo bruto: a rota recebe o `rawBody` do Nest.
- Requisição recusada: `400` sem corpo de fala. Log só com o motivo e IDs.
- Dublê de `ALEXA_REQUEST_VERIFIER` para o e2e, ligado pelo `createTestApp`.
- Construtor de envelopes de teste no `test/support/` (LaunchRequest, IntentRequest com slots, `confirmationStatus` e `sessionAttributes`), reaproveitado pelos tickets seguintes.
- A rota entra na matriz de permissões como pública protegida pelo guard.
- `ALEXA_SKILL_ID` documentado no `.env.example`.

## Critérios de aceite

- [x] **Dado** uma requisição aceita pelo verificador, com `timestamp` dentro de 150 s do `FakeClock` e o `applicationId` certo, **quando** chega ao endpoint, **então** recebe `200` com resposta de voz.
- [x] **Dado** o verificador recusando (assinatura adulterada, sem cabeçalho ou certificado inválido), **quando** a requisição chega, **então** recebe `400` sem fala e o handler não é chamado.
- [x] **Dado** um `timestamp` mais de 150 s antes ou depois do `FakeClock`, **quando** a requisição chega, **então** recebe `400`.
- [x] **Dado** um `applicationId` de outra skill, **quando** a requisição chega, **então** recebe `400`.
- [x] **Dado** o ambiente fora de `test` sem `ALEXA_SKILL_ID`, **quando** a aplicação sobe, **então** a validação de ambiente falha com mensagem clara.
- [x] **Dado** o Echo do TK-07.01, **quando** alguém diz "Alexa, abrir pausa", **então** a saudação continua tocando (resultado na Fase 4 do `docs/alexa/roadmap.md`).
- [x] `npm run test`, `npm run test:e2e`, `npm run lint` e `npm run build` passam.
